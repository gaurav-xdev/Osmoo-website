# OSMOO Website

An animated, editorial landing page for OSMOO, built with React, Vite, Three.js and GSAP.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Experience notes

- Three.js metallic forest-green orb with pointer response and scroll-linked motion.
- GSAP scroll reveals and section choreography.
- Responsive layouts and reduced-motion CSS fallback.
- The companion interface is explicitly presented as a concept preview, not a live product screenshot.

The orb is generated in code. Google Fonts are loaded remotely; the rest of the page styling and interaction is implemented in this repository.
